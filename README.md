News Sentiment and Stock Market Analysis

Project Overview

This project focuses on analyzing financial news sentiment and stock market behavior to identify patterns, trends, and potential relationships between public sentiment and stock price movements.

The project was completed as part of a data analytics challenge focused on:

- Exploratory Data Analysis (EDA)
- Natural Language Processing (NLP)
- Financial Time Series Analysis
- Technical Indicator Analysis
- Sentiment-Based Market Insights

The analysis combines qualitative financial news data with quantitative stock market data to support predictive analytics and investment strategy development.

Business Objective

Nova Financial Solutions aims to improve financial forecasting and predictive analytics capabilities through advanced data analysis techniques.

This project supports that objective by:

- Performing sentiment analysis on financial news headlines
- Identifying market trends using technical indicators
- Exploring relationships between news sentiment and stock price movement
- Building a foundation for sentiment-driven investment strategies
